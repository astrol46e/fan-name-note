FAN NAME NOTE｜登録なし・アプリ画面版
========================================

この版はアカウント登録なしで使う、ローカル保存タイプです。
名義・公演・当落などは、開いたブラウザの localStorage に保存されます。
TimeTree連携・オンライン同期はありません。

重要：iPhoneでホーム画面に追加するには、通常はHTTPSで配信されたサイトが必要です。
このZIPをiPhoneの「ファイル」アプリから直接開くだけでは、ボタンや保存が正しく動かない場合があります。
このパッケージはまだWeb上に公開されていません。公開URLを用意した後、Safariで開いて「共有」→「ホーム画面に追加」を行います。

ファイル：
- index.html : アプリ本体
- manifest.json : ホーム画面表示設定
- sw.js : オフライン用キャッシュ
- icon.svg : アイコン

使い始める前に、まずテスト用データを入れて、再度開いて残るか確認してください。
Safariの履歴・Webサイトデータを消すと、保存データが消える可能性があります。
「バックアップ」機能で定期的にJSONを保存してください。
更新期限は今月が薄い赤、来月が薄い黄色で表示されます。公演一覧は未来・過去に分かれ、当落で絞り込めます。
会員番号などの個人情報は必要以上に保存せず、バックアップファイルを他人と共有しないでください。


【今回の追加機能】
・公演登録に「案内ゲート」欄を追加しました。
・会場資料で、会場ごとの座席表1枚と座席からの写真（複数枚）を登録できます。画像は縮小して保存され、JSONバックアップにも含まれます。
・名義コレクションから「当選履歴」を開くと、当選公演・座席・案内ゲート・会場資料を確認できます。

【更新時の注意】
更新前に、現在のアプリでJSONバックアップを保存してください。今回も保存キーは従来と同じです。既存のJSONバックアップも復元できます。会場画像はブラウザの保存容量を使うため、画像を大量に登録しすぎないようにしてください。


【今回のデザイン改修】
画面全体を、白を基調にした上品でシンプルなファンクラブ会員ページ風に変更しました。淡いピンク・ラベンダー、細い罫線、控えめなアクセントで統一しています。名義・公演・当選履歴・会場資料などの機能と保存データ形式は維持しています。
